# VC Conf 2027 — постер медиапартнёра

Два макета для сервиса vc-conf-partner-decks: вертикальный 1080×1350 (`poster_portrait.html`) и квадратный 1080×1080 для постов в LinkedIn (`poster_square.html`). Оба собраны по актуальному PSD «Participant v6 — Limited Partner». Вместо фото, имени и ссылки стоят плейсхолдеры, а в плашке написано «Media Partner».

## Плейсхолдеры

| Плейсхолдер | Поле в форме | Что подставлять |
| --- | --- | --- |
| `{{company}}` | Компания | Название без LLC / Ltd / Inc и скобок |
| `{{logo_url}}` | Логотип / Сайт компании | URL или data URI логотипа. Пустая строка — белый круг |
| `{{reg_link}}` | Ссылка регистрации | Короткая ссылка без UTM и без https://, например `vcconf.com/?15` |

Имя контакта и промокод на постер больше не выводятся: промокод теперь идёт только в тексты материалов.

## Как рендерить

1. Подставить значения в HTML (обычная замена строк или любой шаблонизатор).
2. Открыть страницу в headless Chromium (Playwright / Puppeteer) с viewport 1080×1350 или 1080×1080.
3. Дождаться `document.fonts.ready`, затем сделать скриншот элемента `#poster`.
4. Имя файла — как и раньше: `VC Conf poster — {name}.png`. Для квадрата можно добавить суффикс, например `VC Conf poster — {name} (LinkedIn).png`.

## Что важно сохранить

- `fit.js` автоматически уменьшает шрифт длинного названия компании (портрет: 58→34 px, квадрат: 52→32 px), базовая линия при этом не сдвигается. Если название не влезает даже на минимальном размере, оно переносится на вторую строку.
- Логотип вписывается в белый круг с отступами (`object-fit: contain`, 74% круга). Прозрачные PNG и SVG подходят лучше всего.
- Шрифт Inter (600/700/800) лежит локально в `assets/fonts`, сеть для рендера не нужна.
- Карточки спикеров — готовые картинки в `assets/speakers` (вырезаны из PSD). Если спикеры на постере поменяются, нужно заменить эти файлы, вёрстку менять не придётся.
- Пути к ассетам относительные: папку `assets` и файлы `poster.css` / `fit.js` держать рядом с HTML.

## Отличия квадрата от вертикали

Блоки и порядок те же. Шрифты чуть меньше, дата и время идут в одной строке с «Hosted by», карточки спикеров уменьшены до 78%. В карточках дней в квадрате оставлены только заголовки, без строки с часами: иначе спикеры становились нечитаемыми.
